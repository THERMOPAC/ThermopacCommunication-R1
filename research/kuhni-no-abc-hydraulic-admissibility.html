2. Existing equations and exact dimensional dependency

D_R = 0.5D; h_c = 0.5D; A = pi D²/4; V = A h_c
P = Np rho_C n³ D_R⁵, with engineering Np = 1.2
psi = P/(rho_C V)
d32 = 0.42 (sigma/rho_C)^0.6 psi^-0.4

Cd = [8(2+3kappa+3lambda)/(Re(1+kappa+lambda))][1+0.15Re^0.687], lambda=0
Np,G = 1.08 + 10.94/Re_R^0.5 + 257.37/Re_R^1.5
vchar/vt = 1 - 1.669Np,G^-3.945 - 2.807[d32/(D-D_R)]^1.336
           - 1.159(h_c/D)^2.049 + 2.1phi_s^1.032
vswarm/vchar = sqrt[(Cd,char/Cd,swarm)(1-h)^4.65]
Uf = max_h(capacity(h)); loading = (Qc+Qd)/(A Uf)

At fixed ratios and fixed engineering Np, P/V ∝ ρCn³D² and ψ ∝ n³D². A variable-diameter RPM 30–70 screen therefore does not preserve P/V, tip speed, rotor Reynolds number, drop size, capacity, or throughput. No reviewed source selects one as a universal Kühni scale-up invariant.

Eq. 8.3 is not an error. The rendered Garthe primary source has already visually verified that the radical spans the complete product, including (1-hd)^4.65. The current closure uses the same inside-radical structure. No equation correction is warranted.

6. Missing constraints — intentionally not invented

  • Actual allowable shaft/motor power, torque, mechanical stress, shaft/bearing/seal/support/vibration limits, and vendor tip-speed limit.
  • Vendor-specific rotor/stator/partition dimensions and shapes, clearances, measured free area, ports, interface control, and active height.
  • Actual throughput/power map, pressure drop, residence time, turndown for these fluids, and outlet/settler capacity.
  • Drop-size distribution, breakage/coalescence, falling shape, and interfacial mobility.
  • Holdup, flooding onset, entrainment, phase inversion, hysteresis, and stable-control observations at target geometry.
  • A source-backed invariant selecting constant tip speed, P/V, rotor Reynolds number, characteristic velocity, or another scale-up rule.
Readiness boundary. Both routes can use their existing independently checked presentation candidate in deterministic HETS pre-pilot arithmetic. Neither route is ready for a safe hydraulic/throughput/power screen or diameter/RPM optimization.
