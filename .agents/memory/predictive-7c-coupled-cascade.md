The production seven-component successor extends the frozen six-component simultaneous coupled cascade rather than repeating standalone stage flashes. Routine TPD uses the denominator-4 seven-component lattice; exhaustive denominator-6 face/edge/adaptive search is deterministic escalation only.

**Why:** The earlier seven-component fixed-point path combined a much denser TPD protocol with repeated stage flashes, making runtime growth unrelated to the addition of dissolved water. It also risked allowing rejected trials to influence continuation.

**How to apply:** Keep each engine contract immutable. Continue only from a branch-reproduced trial with both coupled endpoints closed. Run exactly two post-split TPD searches per solved stage, preserve all acceptance thresholds, and never promote diagnostic results.
