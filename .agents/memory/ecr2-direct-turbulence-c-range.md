name: ECR-2 direct-turbulence C range
description: Evidence boundary for the project-controlled 0.36–0.43 direct-turbulence droplet-size sensitivity interval.
---

The direct-turbulence droplet-size coefficient interval `C = 0.36–0.43` is a
project-controlled preliminary sensitivity interval, not a literature-verified
validity range. A source reference for a selected nominal C provides audit
traceability for that sensitivity point only; it must never be interpreted as
evidence that validates the full interval.

**Why:** The available Kumar & Hartland and Laitinen sources do not jointly
support the exact direct-turbulence equation, its stated C range, Kühni
applicability, ECR-2 phase convention, or RRBO/NMP calibration. Generic
turbulent-breakup references do not close that equipment-and-fluid-specific
evidence gap.

**How to apply:** Keep the route separate from K&H 1996, preliminary, and not
eligible for design or release decisions. Advancement needs an authoritative
equation-and-range source, an explicit ECR-2 applicability decision, RRBO/NMP
pilot validation/calibration, and governed approval.
