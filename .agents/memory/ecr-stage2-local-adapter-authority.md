name: Stage-2 local adapter authority
description: Provenance and runtime-isolation rules for Stage-4 use of the seven-component Stage-2 thermodynamic engine.
---

The Stage-4 local-equilibrium adapter reuses the active frozen seven-component
Stage-2 scientific engine through a separately hashed runtime artifact.
Historical Stage-2 workers, packages, manifests, records, APIs, and replay
remain byte-for-byte independent.

Calculated Stage-2 duty precedence is admitted only from a completed database
job loaded by job ID, authenticated owner, and design, then revalidated against
the active model/engine identity and persisted result contract. Never accept a
caller-supplied result snapshot or a self-computed result hash as calculated
Stage-2 evidence. If trusted calculated evidence is unavailable, run the real
seven-stage engine fallback with `PRE_PILOT_DESIGN_DEFAULT` provenance.

**Why:** A caller can hash arbitrary JSON and relabel a fallback cascade as a
different calculated stage count. Digest consistency proves bytes, not trusted
provenance or agreement between the claimed stage count and the actual duty.

**How to apply:** Keep local composition inputs explicit in frozen
SAT/MONO/DI/POLY/PA/NMP/H2O order. Resolve calculated authority server-side
from persistence; otherwise execute the exact governed fallback. Never infer
PA or water from legacy five-component compartment states.
