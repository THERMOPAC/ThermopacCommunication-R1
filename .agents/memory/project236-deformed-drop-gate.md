---
name: Project 236 deformed-drop gate
description: Governance boundary for RRBO/NMP shape, drag closure, and hydraulic resizing release.
---

Project 236 column resizing must fail closed unless the exact process-property
basis has confirmed local drop-shape evidence, an approved deformation-capable
liquid-drop drag closure, demonstrated Garthe/Stichlmair Eq. 8.3 compatibility,
and explicit optimizer approval. A finite terminal-velocity or hydraulic root
does not satisfy these gates.

**Why:** The available source set supports spherical Barry calculations and
terminal sensitivities, but no unfitted liquid-liquid model was demonstrated in
the required high-viscosity-ratio, low-Morton region. Grace supplies a terminal
point rather than the Reynolds-dependent drag curve needed at characteristic
and swarm-slip states, and Wellek does not provide a binary state boundary.

**How to apply:** Never introduce a fixed Reynolds, Eötvös, Weber, or axis-ratio
shape cutoff. Qualify shape/interface state at each local condition and bind
approval to the active physical-property basis. Project 236 has no separate
research system: diagnostic and held screens are part of the production
workflow, while remaining visibly unapproved for resizing until their gates
pass.
