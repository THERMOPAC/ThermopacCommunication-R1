# Overview
This project is a comprehensive Quality Management System (QMS) for THERMOPAC, a manufacturing and engineering company. It aims to streamline operations and provide enterprise-grade insights across various business modules, including project management, production, quality control, inspections, welding procedures, materials, finance, HR, and document management. The system facilitates data-driven decisions and operational improvements, with a business vision to enhance efficiency and provide a competitive edge in the market.

# User Preferences
Preferred communication style: Simple, everyday language.

# System Architecture
## Core Architectural Decisions
The system is a full-stack web application built on organized, hierarchical data structures, especially for document management and project items. It prioritizes consistent UI/UX through standardized component usage, robust data integrity, and real-time synchronization. Role-based access control governs feature visibility, and comprehensive validation systems ensure data quality. Form design uses dialog-based editing with pre-population and clear visual indicators. Unique IDs are auto-generated for various entities.

## GCS as Single Source of Truth (File Handling Policy)
All file metadata must be retrieved from Google Cloud Storage (GCS) only. Upload/download endpoints resolve canonical GCS keys and interact directly with GCS. UI displays file details from GCS, and the database stores only `gcsKey` identifiers. Security uses signed URLs with short TTL. Client-side caching with react-query is implemented and invalidated on mutations.

## Technical Implementations
- **Backend**: Express.js with TypeScript, PostgreSQL database (Drizzle ORM), session-based authentication, Google Cloud Storage (GCS) for file storage, and a RESTful API.
- **Frontend**: React with TypeScript, Wouter for routing, TanStack Query for state management, Radix UI components with Tailwind CSS, React Hook Form with Zod validation, and Vite for builds.
- **Data Storage**: PostgreSQL on Neon (serverless) for primary data, a dedicated GCS bucket (`thermopac_storage`) for files, and database-backed sessions.
- **UI/UX Decisions**:
    - **Color Schemes**: Consistent use of blue (primary), green (success), red (destructive/warnings), and yellow/orange (warnings/pending).
    - **Templates**: Standardized hierarchical display for project items and work orders using card-based layouts with color-coded badges.
    - **Design Approaches**: Unified dropdowns with role-based grouping and alphabetical sorting, consistent table layouts with streamlined action columns, and professional dialogs.
    - **File Management**: Standardized upload/replacement workflows with GCS integration and user feedback.
    - **Reporting**: Professional PDF and Excel report generation with branded formatting and visual analytics.

## Feature Specifications
- **Project Management**: Tracking of projects, items, and work orders.
- **Quality Management**: Management of inspection orders (Visual, NDT, Weld, Hydrotest, NCR, Shop), material identification, welder management, and welding procedure documents (WPS/PQR/WPQR).
- **Production Management**: Work order generation and resource assignment.
- **Finance Management**: Invoicing, payments, allocations, and BRC tracking.
- **HR Management**: User management, attendance tracking, daily work activity reports, and payroll.
- **Document Management**: GCS integration with hierarchical structure, metadata tracking, template system, and access control.
- **Sales & Marketing**: Lead generation system with AI intelligence (website crawling of homepage/about/contact/services pages, GPT-4o company classification into 11 categories, 5-factor enhanced scoring: industry relevance 30% + business signals 25% + contact availability 20% + company size 15% + urgency 10%, domain+name duplicate detection, CSV export). DB tables: `lead_searches`, `lead_raw_results`, `lead_processed`, `lead_api_quota`. Campaign management, customer management, Product Database with attribute-based product codes (Item Family + Property 1 + Property 2 + Property 3 forming codes like "VAL-GAT-SS3-0200") and parent-child product hierarchy (main products with sub-products like Dehydration Skid, Distillation Skid under a parent plant product — offers quote the parent product price only), and Offers/Quotations module (accessed via "Offers" tab inside the Products page, auto-numbered OFR-2526-0001 (financial year format), customer linking, multi-currency, line items from product database, discount/tax calculations, revision tracking with auto-increment on edits after Sent status, status workflow: Draft→Sent→Approved/Rejected/Expired/Converted — PDF download auto-sets status to Sent, duplicate offers, auto-matched Offer Templates by subject+language for PDF generation).
- **Global Re-Refining Opportunity Radar**: Comprehensive waste oil recycler discovery and intelligence system. 11 DB tables (`radar_*`): `radar_search_jobs`, `radar_search_results`, `radar_sources`, `radar_companies`, `radar_company_pages`, `radar_contacts`, `radar_projects`, `radar_country_intelligence`, `radar_relationships`, `radar_scores`, `radar_alerts`. Features: country-by-country multilingual discovery engine (13+ languages with local-language queries), controlled website crawler (homepage/about/contact/services/products pages), AI classification into 11 company types (used_oil_collector, waste_oil_recycler, re_refiner, etc.), project signal detection (tenders, permits, expansions, new plants), evidence-based confidence scoring (6 dimensions), opportunity scoring (0-100 with weighted factors: feedstock 25% + capital 20% + strategic fit 20% + project signal 20% + geography 10% + contactability 5%, with type-based minimum floors: re_refiner>=45, waste_oil_recycler/base_oil>=35, used_oil_collector with waste_oil>=25), deduplication (domain + name + country), alert engine (critical/high/watch/info), country intelligence with 30 preloaded countries (priority/active/watchlist/paused), CRM promotion with AI-generated outreach notes, CSV export. 8 query families per country: company_discovery, recycler_discovery, base_oil_sellers, regulatory_docs, trade_flow, tradeshow_discovery, directory_mining, project_signal (56 queries per English-only country, more with local language). Directory mining: crawls industry association member pages, regulatory registries, and company directories to extract MULTIPLE companies from a single page (e.g., GEIR members page yields 16 re-refiners at once). Trade show monitoring: IFAT, Ecomondo, Pollutec, UNITI, ICIS, Lubricant Expo, ADIPEC. 3-layer pre-screening: Google query exclusions, domain skip list (60+ domains), keyword relevance filter with anti-keywords. Routes: `server/radar-routes.ts` at `/api/radar`. Frontend: `client/src/pages/radar-page.tsx` at `/radar` with 8 tabs (Overview, Companies, Projects, Countries, Contacts, Alerts, Discovery, Admin).
- **Business Intelligence**: An LLM Prompt Engine for analytics across modules.
- **Travel Management**: Business trip and visa management.
- **Design Management**: Drawing Registry for version control, CAD file management, review/approval workflows, and drawing transmittals.
- **SAP B1 Integration**: Full integration for Purchase Module, including dashboard, quotations, orders, goods receipt, and invoices, with real-time sync, historical data access, and robust error handling. Customer/Business Partner sync: creating or updating a customer automatically pushes the Business Partner to SAP B1 Service Layer (`/b1s/v1/BusinessPartners`) using auto-login with env credentials. Sync service at `server/sap-b1-integration/sap-bp-sync.ts`.
- **Email Management System**: AI-powered Gmail integration with intelligent priority classification (P0-P3), hybrid approach combining hard rules and GPT-4o-mini analysis. Features include mandatory P0 assignment for Income Tax/GST communications and resignation emails, parallel email processing (5 concurrent workers), real-time sync progress tracking, full HTML email display, AI-powered analysis, multi-style reply generation, compose functionality, automatic signature population, and bulk email management actions. System syncs only unread emails from Gmail for optimal performance.
- **API Security**: Measures against SQL injection, XSS, proper authentication middleware, and secure credential management.
