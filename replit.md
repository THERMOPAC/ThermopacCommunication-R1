# Overview
This project is a comprehensive Quality Management System (QMS) for THERMOPAC, a manufacturing and engineering company. It aims to streamline operations and provide enterprise-grade insights across various business modules, including project management, production, quality control, inspections, welding procedures, materials, finance, HR, and document management. The system facilitates data-driven decisions and operational improvements, with a business vision to enhance efficiency and provide a competitive edge in the market.

# User Preferences
Preferred communication style: Simple, everyday language.

# System Architecture
## Core Architectural Decisions
The system is a full-stack web application built on organized, hierarchical data structures, especially for document management and project items. It prioritizes consistent UI/UX through standardized component usage, robust data integrity, and real-time synchronization. Role-based access control governs feature visibility, and comprehensive validation systems ensure data quality. Form design uses dialog-based editing with pre-population and clear visual indicators. Unique IDs are auto-generated for various entities.

## GCS as Single Source of Truth (File Handling Policy)
All file metadata must be retrieved from Google Cloud Storage (GCS) only. Upload/download endpoints resolve canonical GCS keys and interact directly with GCS. UI displays file details from GCS, and the database stores only `gcsKey` identifiers. Security uses signed URLs with short TTL. Client-side caching with react-query is implemented and invalidated on mutations.

## Technical Implementations
- **Backend**: Express.js with TypeScript, PostgreSQL database (Drizzle ORM), session-based authentication, Google Cloud Storage (GCS) for file storage, and a RESTful API.
- **Frontend**: React with TypeScript, Wouter for routing, TanStack Query for state management, Radix UI components with Tailwind CSS, React Hook Form with Zod validation, and Vite for builds.
- **Data Storage**: PostgreSQL on Neon (serverless) for primary data, a dedicated GCS bucket (`thermopac_storage`) for files, and database-backed sessions.
- **UI/UX Decisions**:
    - **Color Schemes**: Consistent use of blue (primary), green (success), red (destructive/warnings), and yellow/orange (warnings/pending).
    - **Templates**: Standardized hierarchical display for project items and work orders using card-based layouts with color-coded badges.
    - **Design Approaches**: Unified dropdowns with role-based grouping and alphabetical sorting, consistent table layouts with streamlined action columns, and professional dialogs.
    - **File Management**: Standardized upload/replacement workflows with GCS integration and user feedback.
    - **Reporting**: Professional PDF and Excel report generation with branded formatting and visual analytics.
